# RiskPoint — Cyber Risk in 3 Questions

**Interactive B2B cyber-risk calculator prototype**, created for the 180HEARTBEATS AI Prototype Builder task.

**[Live demo](https://kakalooka.github.io/RiskPoint/)** · [Approved HTML](final/RiskPoint-final.html) · [Release status](docs/FINAL.md) · [Repository state](docs/REPOSITORY_STATE.md)

Three deliberate steps: **Industry → Annual revenue → MFA coverage → LOW / MID / HIGH result**. A separately computed illustrative financial-impact range and a protection-oriented CTA follow. No registration is required to see a result. There is no backend and the lead form does not submit real data.

## Architecture
- React 19 / TypeScript / Vite 8 / plain CSS / Sora / Vitest 5.
- Deterministic scoring in `src/model/` (prototype heuristics, **not** actuarial underwriting).
- UI in `src/components/`, display copy in `src/content.ts`, styles in `src/styles/`.
- 140 input combinations covered by model tests, plus golden and revenue-copy tests.
- The published demo is a standalone HTML artifact; it is deliberately not regenerated by GitHub Pages during cleanup.

## Run and verify

Requires **Node.js 22.12+ on the 22.x line, Node 24.x or Node 26+** (per locked Vitest engines) and npm.

```bash
npm ci
npm run dev
npm test
npm run build:all
npm run verify:release
```

`build:all` emits a web build and `dist/RiskPoint.html`. `verify:release` compares the generated standalone HTML **byte for byte** to the approved, frozen `final/RiskPoint-final.html`. Mismatch means **STOP**, not an instruction to overwrite the approved artifact.
